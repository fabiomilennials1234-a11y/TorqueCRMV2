# Second Brain — Obsidian Vault Update

Update the Torque vault (`Torque-dir-new/`) with changes from this session.

## What to update

1. **Feature docs** — If a feature was implemented/modified, update its spec in `06 - Funcionalidades/` or `07 - Features/`
2. **Sistema Base** — If base infrastructure changed, update `05 - Sistema Base/Checklist Sistema Base.md`
3. **ADRs** — If an architectural decision was made, create/update in `08 - Decisoes/`
4. **Backlog** — If tasks were completed, update `09 - Backlog/Plano Mestre de Finalizacao do SaaS CRM.md`
5. **State** — Update `.specs/project/STATE.md` with new decisions and blockers
6. **Index** — If status changed, update `00 - Indice.md` status section

## Rules
- NEVER leave vault stale after significant work
- ALWAYS update checklist items that were completed
- ALWAYS note any divergences discovered between docs and code
- Keep notes concise and factual
