# PROJECT.md — Torque CRM v2

## Vision
Multi-tenant B2B SaaS CRM for Brazilian sales teams that sell via WhatsApp, with embedded AI (Copilot) and unified multi-channel operation.

## Goals
1. **WhatsApp-first CRM** — Kanban pipelines, DnD, realtime, optimized for high-volume lead qualification
2. **AI-augmented selling** — Copilot agents that qualify, schedule, follow-up autonomously with guardrails
3. **Self-service multi-tenancy** — Onboarding wizard, checkout, PIX billing, quota enforcement, feature flags
4. **Workflow automation** — Visual DAG builder (12+ node types), campaign dispatch, event-driven triggers
5. **Operational intelligence** — Funnel analytics, UTM attribution, team ranking, Oraculo Comercial (AI coach)

## Product Boundaries

### In scope
- Lead management with multi-pipe kanban (WhatsApp, Confirmacao, Propostas, Custom)
- Multi-channel inbox (WhatsApp, Instagram, Messenger, SZ.Chat)
- AI Copilot with RAG, TTS, configurable personality
- Visual workflow builder with 12+ node types
- Outbound campaigns with segmentation
- Team management with commissions, goals, gamification
- Analytics with Visx charts, CSV export
- Master Admin with cross-org operations
- Checkout with PIX (Asaas), plan provisioning

### Out of scope
- Mobile native app (PWA post-F09)
- Email marketing (not core channel)
- Social media posting/scheduling
- E-commerce / product storefront
- Project management features

## Technical Profile
- **Frontend:** React 18 SPA + TypeScript strict + Vite + TanStack Query
- **Backend:** Go HTTP/2 server + PostgreSQL 15+
- **Realtime:** WebSocket hub (nhooyr.io/websocket) with tenant isolation
- **Auth:** httpOnly cookies + JWT + RBAC 4 layers
- **Contracts:** OpenAPI generated by Go, consumed by frontend via openapi-typescript
- **Design:** Dark-first, editorial typography, accent gold hsl(44 93% 54%)
